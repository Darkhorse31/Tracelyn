# Signed updater releases

The desktop app checks on startup and every 24 hours when automatic checks are enabled. Settings stores that preference locally, enabled by default. A manual check is always available. Available updates show their version and plain text release notes in a dismissible toast. Install and Restart downloads and verifies the artifact before installation.

## Generate the updater key

From the project root:

```powershell
npx tauri signer generate -w "$env:USERPROFILE\.tauri\tracelyn.key"
```

Save the private key and password in your release secret store. Keep an offline backup. Paste the generated public key into `plugins.updater.pubkey` in `src-tauri/tauri.conf.json`. Replace `OWNER` in the updater endpoint with your GitHub owner. Never put a private key into source control or the app.

`bundle.createUpdaterArtifacts` is false in `src-tauri/tauri.conf.json`. A plain `npm run tauri build` finishes without updater signatures and without any signing secret. Release builds merge `src-tauri/tauri.release.conf.json`, which sets `createUpdaterArtifacts` to true.

For a release shell or CI job:

```powershell
$env:TAURI_SIGNING_PRIVATE_KEY = Get-Content -Raw "$env:USERPROFILE\.tauri\tracelyn.key"
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = '<private key password>'
npm run tauri:release
```

`npm run tauri:release` runs `tauri build --config src-tauri/tauri.release.conf.json` and stops immediately when `TAURI_SIGNING_PRIVATE_KEY` is missing. An Authenticode certificate is independent of this updater key.

## GitHub manifest

Upload `latest.json` as a release asset alongside the generated installer and its `.sig` file. Use the exact installer filename generated by your selected bundle target. Example:

```json
{
  "version": "0.2.0",
  "notes": "Improved server monitoring and reliability.",
  "pub_date": "2026-10-28T12:00:00Z",
  "platforms": {
    "windows-x86_64": {
      "signature": "CONTENTS_OF_INSTALLER_SIG_FILE",
      "url": "https://github.com/OWNER/tracelyn/releases/download/v0.2.0/Tracelyn_0.2.0_x64-setup.exe"
    }
  }
}
```

`signature` is the complete text from the corresponding `.sig` file, JSON escaped as needed. Do not use the signature filename or an Authenticode signature here. Add separate entries for other shipped architectures. Publish only artifacts generated after Windows signing has finished. Modifying an installer after generating its updater signature invalidates that signature.

Test an upgrade from an older installed version. Verify that altered installers are rejected, release notes display, manual checks report offline errors, and disabling automatic checks survives restart.

References: [Tauri updater](https://v2.tauri.app/plugin/updater/) and [Tauri signer CLI](https://v2.tauri.app/reference/cli/).
